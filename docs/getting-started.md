# Getting started

The short version is one page: **[Start](start.md)** — an existing project or
a new one, six commands each.

Install it in a project that has a `package.json`:

```bash
npm install --save-dev @rsaglobaltech/specgate
npx specgate --help
```

Anywhere else, run it without installing: `npx @rsaglobaltech/specgate@latest`
in place of `specgate`.
