# Proposal: live-questions

## Intent

The live view took an answer only for a question the agent asked; the open questions of a draft, and requirements waiting in Needs Clarification, still needed a terminal.

## Scope

In scope:

- An "Open questions" section in the live view, with the answer form for each question (REQ-203).

Out of scope:

- Asking a new question from the page.

## Approach

The live model carries what `specgate questions` lists; the page reuses the answer form of REQ-201.
