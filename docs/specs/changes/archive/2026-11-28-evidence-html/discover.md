# Discover: evidence-html

> Owner: product — what the business needs and why. No technology here: the
> design says how.

## Context

The evidence page is Markdown: it reads well inside a pull request, and
nowhere else. Shown a hand-made web version of it on 2026-11-27 — screens
side by side, the runs, the calls and the diagrams on one page — the person
asked for Specgate to write that page itself.

## Use case

The reviewer opens one file, with no repository and no server, and reads the
change's evidence; the Developer gets it opened in the browser as it is
written.

## Acceptance criteria

- AC-1: the evidence is also written as one page that opens with no server, its pictures inside it, in English.
- AC-2: the Developer can have it opened in the browser as it is written; no browser is opened in a pipeline.
