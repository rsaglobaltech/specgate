# Discover: workspace-live-port

> Owner: product — what the business needs and why. No technology here: the
> design says how.

## Context

A workspace's live view — every repository's work, each story's parts, the
cost — was a page of its own, apart from the studio people use for everything
else, and each repository's view another. Opened in a workspace, the studio's
own Live section could not read the workspace and showed nothing useful.

## Use case

A lead opens the studio of a workspace, sees what each repository is building
and what each story waits on, and opens one repository's work from there.

## Acceptance criteria

- AC-1: The studio's Live shows, in a workspace, each repository's work and cost and each story's parts.
- AC-2: Each repository leads to its own Live, read only, and back.
- AC-3: The addresses and the data a tool reads stay as they were.
