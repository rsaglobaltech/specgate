# Discover: parallel-drafts

## Context

A module takes about three minutes to draft, nearly all of it the agent writing; the studio drafts seven modules one after another. Drafted at once, each agent's confinement undid the other's files: it took them for its own writes outside its change.

## Acceptance criteria

- AC-1: two drafts at once keep each other's files, and anything else outside the change is still undone.
