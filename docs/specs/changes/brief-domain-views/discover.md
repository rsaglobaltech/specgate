# Discover: brief-domain-views

## Context

Issue #59 of the studio, both ways: after a workshop is imported, and also when the brief was written by hand, the team wants to see the domain as DDD diagrams — a context map, each context's flows as an Event Storming — and to take it back to the workshop tool to go on with the domain experts.

## Acceptance criteria

- AC-1: the project's domain model is read for drawing, from the workshop or from the specification, and says which.
- AC-2: the model is exported as boards the workshop tool opens, in its file format only; read back, they give the same model.
