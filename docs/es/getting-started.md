# Primeros pasos

La versión corta cabe en una página: **[Empezar](start.md)** — un proyecto
existente o uno nuevo, seis comandos cada uno.

Instálalo en un proyecto que tenga un `package.json`:

```bash
npm install --save-dev @rsaglobaltech/specgate
npx specgate --help
```

En cualquier otro lugar, ejecútalo sin instalar: `npx @rsaglobaltech/specgate@latest`
en lugar de `specgate`. Instalado, también responde al nombre más corto `sgate`.
