# Code of conduct

Specgate adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct. This page says what it means here and how to reach the
maintainers; the Covenant's own text is the reference.

## What we expect

Everyone who takes part — in issues, pull requests, discussions, reviews and any space the project
runs — is welcome, whatever their background or experience. We expect people to:

- be kind and patient, and assume good faith;
- give and take criticism of work, never of people;
- write so that someone new to the project can follow, in plain words;
- accept that a maintainer's "no" to a change is about the change.

Harassment, insults, personal or political attacks, sexualised language or imagery, publishing
someone's private information, and any conduct a reasonable person would find inappropriate in a
professional setting are not accepted.

## Reporting

Report a problem privately to the maintainers through
[GitHub private reporting](https://github.com/rsaglobaltech/specgate/security/advisories/new) — the
same private channel as [SECURITY.md](SECURITY.md); say in its title that it is about conduct. Every
report is read, answered and kept confidential. If a maintainer is involved, say so and another one
handles it.

## Enforcement

The maintainers decide what happens, in proportion, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a correction, a warning, a temporary ban, or a permanent ban. They may remove or edit comments,
commits, issues and other contributions that do not follow this code.

## Scope

This code applies in every space of the project, and when someone represents the project in public.
